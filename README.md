# СканРецепт 🍳

PWA-приложение: наводи камеру на продукты или штрих-код — получай рецепты из того, что есть.

- **Каталог 100 рецептов** (8 категорий, фильтры по ккал, поиск)
- **Сканирование фото** — распознавание продуктов и подбор «что приготовить» + «добавь один продукт»
- **Штрих-код** — товар по EAN из открытой базы Open Food Facts (КБЖУ на 100 г)
- **Запасы дома** — кухонный шкафчик с баночками, подбор рецептов из запасов
- **Список покупок** — отдельный таб, тумблеры «куплено», группировка по рецептам
- **КБЖУ и порции** — КБЖУ на порцию (PRO), пересчёт ингредиентов по порциям (Лайт 1–2, PRO до 12)
- **5 тем оформления** — светлая, тёмная, бордо, лесная, океан
- **Офлайн** — service worker, установка на домашний экран (PWA)

## Стек

Vite 7 · React 19 · TypeScript · Tailwind CSS 4 · Zustand 5 (persist) · React Router 7 · vite-plugin-pwa · @zxing/browser

## Локальный запуск

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # прод-сборка в dist/
npm run preview    # проверка сборки (с API-эндпоинтами)
```

## Публикация на Vercel

### Вариант 1 — через GitHub (рекомендую)

1. Запушь проект в репозиторий GitHub.
2. Открой [vercel.com/new](https://vercel.com/new) → импортируй репозиторий.
3. Vercel сам определит Vite: Build `npm run build`, Output `dist/`. Жми **Deploy**.
4. Через ~минуту получишь ссылку вида `https://skan-recept.vercel.app` — можно делиться с друзьями.

### Вариант 2 — через CLI

```bash
npm i -g vercel
vercel login       # один раз
vercel --prod      # из корня проекта
```

### Распознавание фото (необязательно)

Штрих-коды, каталог, запасы, список покупок и темы работают сразу после деплоя — без настроек.
Чтобы **фото-скан** распознавался по-настоящему, добавь в Vercel (Settings → Environment Variables)
переменные любого OpenAI-совместимого vision-провайдера:

| Переменная       | Пример значения                |
| ---------------- | ------------------------------ |
| `VISION_BASE_URL` | `https://api.z.ai/v1` или `https://api.openai.com/v1` |
| `VISION_API_KEY`  | твой ключ                  |
| `VISION_MODEL`    | `glm-4.5v` / `gpt-4o-mini` |

> ⚠️ Раньше код читал только имена `AI_BASE_URL`/`AI_API_KEY`/`AI_MODEL` — если переменные
> заданы под старыми именами, они тоже работают (это алиасы того же слота).

Проще всего — бесплатный OpenRouter (открыт из РФ): задай одну переменную
`OPENROUTER_API_KEY` (ключ с openrouter.ai), модель подставится сама.
Ещё вариант — `GEMINI_API_KEY` (Google AI Studio). Порядок выбора провайдера:
`VISION_*`/`AI_*` → `OPENROUTER_API_KEY` → `GEMINI_API_KEY`.

Без них `/api/scan` отвечает `501`, а приложение честно предлагает демо-скан и штрих-коды.
Локально в dev-режиме распознавание работает через встроенный плагин (`scan-api.ts`).

> Важно: зеркала на GitHub Pages (`hopmyl.github.io` и `/scanfood/`) — статические,
> серверных функций там нет, фото-скан на них всегда демо. Настоящее распознавание
> — на Vercel-адресе приложения.

### Структура серверной части

- `api/scan.ts` — Vercel Function: распознавание фото (vision-модель)
- `api/barcode.ts` — Vercel Function: товар по штрих-коду (Open Food Facts, без ключей)
- `scan-api.ts` — те же эндпоинты внутри `vite dev`/`vite preview` для локальной разработки

## Альтернатива: Netlify Drop (за 30 секунд, без git)

```bash
npm run build
```

Затем перетащи папку `dist/` на [app.netlify.com/drop](https://app.netlify.com/drop) —
SPA-редиректы уже настроены (`public/_redirects`), штрих-коды работают из браузера напрямую.
