Метрика этапа
1Триггер вечер, продукты есть — идей нет
  • Открывает холодильник, оценивает остатки
  • Перебирает знакомые блюда «по кругу»
  • «Опять готовить то же самое»
  • Жалко выбрасывать несвежие продукты
офлайн, быт
Момент потребности — приложение должно быть уже установлено
частота: ежедневно
2Поиск идеи выбор источника рецептов
  • Ищет «что приготовить из …» в Яндексе
  • Спрашивает ИИ-чат / Алису, листает VK и Telegram
  • Рецепты не подходят под её набор продуктов
  • Длинные статьи, реклама, всплывающие окна
Яндекс, Google, YouTube, VK, Telegram, Алиса/ChatGPT
SEO-страницы «рецепты из …», соцсети, каталог открыт по ссылке без установки
показы, CTR в поиск
3Знакомство первый контакт с продуктом
  • Открывает лендинг/PWA, листает каталог
  • Смотрит фото, КБЖУ, фильтры
  • «Зачем ещё одно приложение?»
  • Недоверие: снова реклама и подписки
лендинг, каталог, отзывы друзей
399 блюд с фото без регистрации; честно: без рекламы, фильтры время/сложность
лендинг → установка 25–40%
4Активация момент истины — первый скан
  • Фотографирует полку холодильника
  • Подтверждает распознанное, получает подборку «можно приготовить»
  • Страх: «не распознает мои продукты»
  • Не хочет вручную вбивать запасы
приложение
Скан фото + штрихкода → список продуктов с уверенностью → подбор по реальным запасам — уникальность на рынке РФ
40–55% установок
5Готовка и повтор формирование привычки
  • Готовит по рецепту, сохраняет в избранное
  • Возвращается: запасы уже сохранены
  • Телефон гаснет над кастрюлей, мелкий шрифт
  • Без режима готовки возвращается в заметки
приложение, PWA-иконка на столе
Персистентные запасы, избранное, фильтры «до 15 мин», «лёгкая»; режим готовки — приоритет №1 роадмапа
возвраты D7/D30
6Монетизация PRO и рекомендация
  • Упирается в лимит Лайта (5 сканов/день)
  • Хочет авторские коллекции → оформляет PRO, делится рецептом
  • «А не обманут ли с подпиской?»
  • Не любит навязчивые офферы
приложение, соцсети
Один честный апгрейд-момент: 151 авторское блюдо; без рекламы и тёмных паттернов
PRO 1–3% активных; шеринг 8–12%
Оранжевая строка — момент истины: уникальная связка «скан → запасы → подбор», которую не воспроизводят ни контент-сайты, ни ИИ-чаты. Конверсии — ориентиры категории (RevenueCat 2025).
